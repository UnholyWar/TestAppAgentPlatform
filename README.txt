GMIA - HTML/CSS/JS Web Sitesi

1. index.html dosyasını tarayıcıda açın.
2. assets/images/ klasörüne şu dosyaları koyun:
   logo.png
   hero-1.jpg, hero-2.jpg, hero-3.jpg
   proje-1.jpg, proje-2.jpg, proje-3.jpg, proje-4.jpg, proje-5.jpg, proje-6.jpg
3. Proje başlıklarını/açıklamalarını script.js içindeki projects dizisinden düzenleyin.
4. Telefon, e-posta ve adres bilgilerini index.html içinden güncelleyin.
5. CSS renkleri style.css başındaki :root değişkenlerindedir.
6. Sitede örnek iletişim bilgileri kullanılmıştır. Canlıya almadan önce değiştirin.
7. İletişim butonu mailto: bağlantısıdır, sunucu taraflı form bulunmaz.

Yerel çalıştırma: index.html çift tıklayın veya python -m http.server 8000
